# Sentinel dependency entry point — installs the full development environment
# (runtime + test/dev tooling):
#
#     pip install -r requirements.txt
#
# Layered structure:
#   requirements-runtime.txt  production pins only (used by the Docker image)
#   requirements-dev.txt      test/dev pins, layered on the runtime pins
#
# This file stays the single documented install command so the existing
# workflow (Makefile `setup`, CI, README/REPRODUCE instructions) is unchanged.
-r requirements-dev.txt
